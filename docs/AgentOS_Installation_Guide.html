1
One-Line Install

macOS & Linux

# Jean-Pierre (PM) — default
curl -fsSL https://unicolab.github.io/agentos/install.sh | sh

# Michelle (Analytics)
curl -fsSL https://unicolab.github.io/agentos/install.sh | sh -s -- --flavour michelle

# Brigitte (Management)
curl -fsSL https://unicolab.github.io/agentos/install.sh | sh -s -- --flavour brigitte

# All agents at once
curl -fsSL https://unicolab.github.io/agentos/install.sh | sh -s -- --flavour all

Windows (PowerShell)

irm https://unicolab.github.io/agentos/install.ps1 | iex

3
What the Installer Does
Checks dependencies — verifies curl/wget and tar
Detects platform — identifies OS and CPU architecture
Validates connectivity — confirms GitHub API is reachable
Fetches latest release — finds the newest version for your flavour
Downloads & extracts — 3-attempt retry with exponential backoff
macOS security — clears Gatekeeper quarantine + ad-hoc code signs
Installs binary — to /usr/local/bin (admin) or ~/.local/bin (user)
Updates PATH — adds install dir to your shell config
Installs fleet manager — creates the agentos dispatcher
Launches the agent — opens the web UI at localhost:18080
4
Running Your Agent

Start directly

agentos-pm serve          # Jean-Pierre
agentos-michelle serve    # Michelle
agentos-brigitte serve    # Brigitte

The web UI opens at http://localhost:18080 — port auto-increments if occupied.

Fleet Manager — manage multiple agents with one command:

agentos list              # show installed agents + status
agentos start michelle    # start Michelle
agentos stop michelle     # stop Michelle
agentos restart brigitte  # restart Brigitte
agentos status            # running/stopped overview

5
Data Isolation

Each agent maintains fully isolated storage — agents never share data:

~/.agentos/ ├── aiflow-pm/ # Jean-Pierre │ ├── agentos.db # Local database │ ├── skills/ # Installed skills │ └── config/ # Configuration ├── michelle/ # Michelle │ ├── agentos.db │ └── skills/ └── brigitte/ # Brigitte ├── agentos.db └── skills/
✅ Safe to run all agents simultaneously — ports auto-increment: :18080, :18081, :18082
6
Licensing

AgentOS requires a license key for full operation. Each agent validates against the Watchtower licensing platform.

Activation is simple: on first startup, the agent prompts you to paste your license key directly in the web UI. No file editing required.

Alternatively, you can place a .watchtower.json configuration file in the agent's data directory before starting:

cp .watchtower.json ~/.agentos/<flavour>/

To obtain a license, contact info@unicolab.ai.

7
Automatic Update Notifications

Agents automatically detect when a new version is available and notify you through:

  • 🔔 Web UI — real-time notification banner
  • 📦 CLI — version info when running agentos-<flavour> license
  • 📡 API — programmatic access via GET /v1/update/status
⚠️ Updates are user-controlled — the agent notifies but never auto-updates.
